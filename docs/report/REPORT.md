## Служебное техническое обновление: Zed, 2026-10-17

**AI-справка для личной проверки студентами, не авторский раздел архитектуры.**
Добавлены отдельная Tree-sitter-грамматика для редактирования `.emb`, конфигурация
Zed, запросы подсветки/скобок/отступов/outline и задачи сборки компилятора,
проверки сохранённого файла, вывода IR и ARM assembly. Основной ANTLR parser,
язык, AST, IR, backend и firmware не изменены. Диагностика выводится в терминал
с исходными координатами; LSP/Problems в Zed не реализованы.

Повторно проверены VS Code и прежние этапы. Итог текущего запуска — **221
успешная автоматизированная проверка**: 160 прежних + 37 VS Code + 24 Zed.
Собран настоящий WASM-парсер, проверены все пять `.emb` примеров и запросы
подсветки. Zed отсутствует в среде: установка, внешний вид и клики по ошибкам
в самом редакторе **не подтверждены**. Это компонентная проверка, не аппаратный
результат и не полная приёмка editor integration. Методика, ограничения и
команды — в [журнале](VERIFICATION.md) и [приложении H](APPENDICES.md#h-zed-локальный-прототип).

Требование стр. 10 об отладке GDB/gdb-stub через TCP/IP остаётся невыполненным
в обоих редакторах. Нужны согласованный ELF с отладочной информацией и привязкой
к `.emb`, GDB remote target, editor/debug adapters и проверки breakpoints,
step/continue, стека и переменных. В этой работе это не реализуется.
Изменения не закоммичены и не опубликованы; плата не подключалась.
