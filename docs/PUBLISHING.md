# Public snapshot provenance

Publication was explicitly authorized on 2026-10-17 for the GitHub repository
`qusaeotoman/EmbedLang`, with new public Git history. The original local milestone
is `5f8a6b713b60a2e89089394ab96f6e0200395381`; its history remains local and is not
rewritten or uploaded. The local project files are unchanged by the publication
process. The README and portable documentation were prepared separately.

The originally approved 175-file source snapshot was reduced under the user's
instruction to exclude third-party files without established redistribution
permission. Six upstream files were omitted and PUBLICATION_NOTES.md was added,
leaving 170 source/documentation/test/vendor files before local build outputs.
See [the exclusion list](../PUBLICATION_NOTES.md) for the exact files, preserved
notices and resulting OLED rebuild limitation. No project-wide license was
assigned to the original EmbedLang code.

Source publication excludes credentials, personal filesystem paths, firmware
binaries, Flash readbacks, programming logs, machine-local configuration, tool
installations and the original Git metadata/history. The public initial commit
uses the GitHub user's noreply address. Scans are heuristic and do not constitute
an absolute guarantee about arbitrary data; private data is never intentionally
included. Public third-party author names and notices remain as attribution.

The full original local milestone passed 160 checks and was physically validated
by the user before publication. The source-only public snapshot omits OLED/font
components and ignored preservation fixtures, so that historical count is not a
claim that all firmware suites run from a fresh public clone. The portable
compiler suite and available firmware builds are verified separately during
publication. No hardware access or flashing is performed by publication tools.
